# VibeC - 极速语音编码助手 (Qwen3-ASR 专版)

VibeC 是一个专为 Coding 与高频文本输入场景设计的极速开源语音打字助手。
底层基于阿里通义实验室 2026 最新开源的 **Qwen3-ASR** 语音大模型，深度结合 **Intel Arc 显卡硬件加速** 与 C++ 极速推理引擎 **sherpa-onnx**。采用全局无冲突热键 `Win + Shift + H`，实现超低延迟的“话音刚落，代码上屏”。

本项目全面专注并支持 Qwen3-ASR 双版本：
1. **Qwen3-ASR 0.6B (极速版)**：端到端推理仅需 0.2 秒左右，超轻量级，极速上屏。
2. **Qwen3-ASR 1.7B (旗舰高质量版)**：参数量近 3 倍提升，商用级转写精度，针对中英文混杂、复杂代码术语和方言口音具备顶级识别效果。

---

## 🌟 核心特性
- **双芯片异构硬件加速**：
  - **AMD NPU / DirectML 加速**：全面支持 **AMD Ryzen AI (NPU) 与 Radeon 集显 (如 780M / gfx1103)**，特征提取与 Encoder 卸载至 NPU / DirectML，中长句转写提速 **1.37x**，大幅降低 CPU 负载与发热。
  - **Intel Arc 显卡加速**：支持针对 **Intel(R) Arc(TM) 130T GPU (8GB)** 进行 OpenVINO 异构运算加速。
- **双版本自适应探测**：启动时自动扫描当前目录，若存在 1.7B 高质量模型则优先调度，否则平滑运行 0.6B 极速版。
- **多显示器自适应**：智能检测鼠标所在当前活动屏幕，精准居中于当前主视线显示器正上方。
- **极简灵动胶囊悬浮小条 (Floating Bar)**：屏幕顶部常驻半透明悬浮胶囊，支持**鼠标直接点击**开始录音与结束上屏，支持鼠标任意拖拽摆放；底层搭载 Windows `WS_EX_NOACTIVATE` 属性，鼠标点击绝不抢走原编辑器光标焦点。
- **免字符污染功能热键 (F8 / Win+Shift+H)**：推荐使用单键 **`F8`** 唤醒与结束，由于是系统功能键，在代码编辑器或任意输入框中按下**绝不产生任何字符输出**；同时向后兼容三键组合 `Win + Shift + H`。
- **双色域主题**：支持暗黑模式 (极客黑半透明-青紫发光) 与明亮模式 (极简白半透明-深灰) 一键切换。
- **免打扰后台托盘**：完全托盘化运行，可右键随时控制小条显示/隐藏，不占用任务栏。

## 🚀 3. 如何使用

### 一键脚本启动（推荐）

| 模式 / 加速硬件 | 启动脚本 (控制台窗口) | 静默启动 (无窗口常驻) | 命令行启动方式 |
| :--- | :--- | :--- | :--- |
| **AMD NPU 硬件加速版 (推荐)** | `start_amd_npu.bat` | `start_amd_npu_silent.vbs` | `python demo_qwen3_asr.py --amd-npu` |
| **CPU 原生极速版** | `start_vibec.bat` | `start_vibec_silent.vbs` | `python demo_qwen3_asr.py` |

*(如果快捷键由于权限不足无法触发全局响应，请尝试以**管理员身份**运行终端或 IDE 再执行)*

### 两种交互方式（鼠标点击 / 快捷键均可）：
1. **开始录音**：
   - **方式一（鼠标点击）**：用鼠标单击屏幕顶部的【悬浮小条】，小条瞬间变红并启动录音计时。
   - **方式二（单键快捷键）**：在任意输入窗口光标处，轻按键盘 **`F8`**（或按组合键 `Win + Shift + H`）。
2. **开始讲话**：对着麦克风说出您的代码逻辑或日常文本。程序最长支持单次 60 秒的录音保护。
3. **结束并上屏**：
   - 再次**单击悬浮小条**（或轻按键盘 **`F8`**）。
   - 小条显示 `⚡ 正在极速识别...`，Qwen3-ASR 识别出的文字将在瞬间自动打入在您的鼠标光标处，并提示 `✅ 已上屏`。

### 悬浮条特色操作：
- **随意拖动**：按住悬浮小条的任意空白区域，即可轻松拖拽到屏幕任意习惯的位置。
- **右键菜单**：右键单击小条即可切换【🎨 切换主题】或【📌 恢复顶部居中】。
- **系统托盘**：屏幕右下角托盘图标支持右键【👁️ 显示/隐藏悬浮条】或【❌ 完全退出】。

## 📦 4. 打包为独立 EXE 桌面软件与模型存放说明

### 🌟 方式 A：一键全自动打包与部署 (强烈推荐)

本项目内置了一键自动化打包脚本，会自动完成依赖编译并自动把模型文件夹部署到位：

```bash
python build_dist.py
```
执行完毕后，直接进入 `dist/demo_qwen3_asr/` 双击 `demo_qwen3_asr.exe` 即可直接使用！

---

### 🛠️ 方式 B：手动打包与放置模型说明

如果您使用的是原生 PyInstaller 命令打包：

```bash
python -m PyInstaller demo_qwen3_asr.spec
```

打包成功后，PyInstaller 会在 `dist/` 下生成一个独立运行包文件夹：`dist/demo_qwen3_asr/`。

#### ⚠️ 关键步骤：模型文件该放在哪里？
请将项目根目录下下载好的 **`sherpa-onnx-qwen3-asr-0.6B-int8`** 文件夹，**完整复制到 `dist/demo_qwen3_asr/` 目录下（即与 `demo_qwen3_asr.exe` 同级）**。

#### 📂 最终完整的绿色发布包目录树结构如下：

```text
dist/
└── demo_qwen3_asr/                           <-- 最终可拷贝分发的绿色完整文件夹
    ├── demo_qwen3_asr.exe                    <-- 核心主程序 (双击直接运行)
    ├── _internal/                            <-- 系统核心依赖与动态链接库
    └── sherpa-onnx-qwen3-asr-0.6B-int8/      <-- 【关键】必须放在这里的模型文件夹
        ├── conv_frontend.onnx                <-- 特征提取前端网络
        ├── encoder.int8.onnx                 <-- INT8 编码器网络
        ├── decoder.int8.onnx                 <-- INT8 解码器与 KV Cache 网络
        └── tokenizer/                        <-- 词表分词器目录
```

> **💡 贴心提示 (智能多级自动回溯)**：
> 程序已内置智能多级回溯功能。如果您在开发阶段打完包后直接在 `dist/demo_qwen3_asr/` 下双击 `demo_qwen3_asr.exe`，程序会自动向上回溯两级，优先自动复用项目根目录下的模型文件；若把该文件夹拷贝到其它电脑，请务必保证上述目录树结构完整。

## 📊 5. 性能基准评测结论 (CPU vs. AMD NPU / DirectML)

本项目在 **AMD Ryzen 7 H 255 + Radeon 780M / AI 硬件加速单元** 平台上进行了严谨的独立基准评测，完整技术报告请参见：👉 **[BENCHMARK_REPORT.md](BENCHMARK_REPORT.md)**。

### 核心实测数据汇总 (Qwen3-ASR 0.6B)

| 语音输入时长 | CPU 原生版 (`sherpa-onnx`) | AMD NPU 硬件加速版 (`DirectML`) | 硬件加速比 / 对比结论 |
| :---: | :---: | :---: | :---: |
| **2.0 秒** (短命令/短语) | **550.0 ms** (RTF: 0.275) | **551.5 ms** (RTF: 0.276) | **基本持平** (差异 < 1.5ms) |
| **5.0 秒** (标准代码/注释) | **886.1 ms** (RTF: 0.177) | **647.5 ms** (RTF: 0.129) | 🚀 **NPU 快 1.37 倍** (节省 **238ms**) |
| **10.0 秒** (长句/连续阐述) | **1456.0 ms** (RTF: 0.146) | **1144.2 ms** (RTF: 0.114) | 🚀 **NPU 快 1.27 倍** (节省 **312ms**) |
| **冷启动耗时** | **3.69 秒** | **9.33 秒** | CPU 版冷启动更快 (DML 需首发图编译) |
| **物理内存 (RSS)** | **1155 MB** | **1450 MB** | NPU 版多占约 295 MB 硬件显存上下文 |
| **CPU 负载与功耗** | **4 核心瞬时 100% 满载** | **大幅降低 (卸载至硬件单元)** | 显著降低发热与风扇噪音，极佳续航 |

### 生产建议
- **追求极速长句输入 & 降发热**：首选 **AMD NPU 硬件加速版**（运行 `start_amd_npu.bat`）；
- **内存极度敏感 & 极速冷启动**：选用 **CPU 原生版**（运行 `start_vibec.bat`）。
